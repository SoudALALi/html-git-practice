# HTML-Git-Practice

هذا المشروع عبارة عن صفحة HTML بسيطة تستخدمها للتدريب على Git وGitHub.

## الأوامر الأساسية

- `git init` — تهيئة مستودع Git جديد في المجلد الحالي
- `git status` — عرض حالة الملفات (المعدّلة، المجهّزة، غير المتتبعة)
- `git add .` — إضافة جميع التغييرات إلى منطقة التجهيز
- `git commit -m "رسالة التعديل"` — حفظ التغييرات مع رسالة توضيحية
- `git push origin main` — رفع التغييرات إلى GitHub
- `git pull` — سحب آخر التحديثات من المستودع البعيد

## الفروع (Branches)

- `git branch` — عرض جميع الفروع
- `git checkout -b feature-name` — إنشاء فرع جديد والتبديل إليه
- `git merge feature-name` — دمج فرع مع الفرع الحالي
- `git branch -d feature-name` — حذف فرع

## نصائح مهمة

تذكّر: اكتب رسائل commit واضحة ومفيدة، لأنها تساعدك أنت وفريقك على فهم تاريخ المشروع لاحقاً.

## هدف التدريب

- التدرّب على إنشاء المستودعات (repositories)
- التمرّن على الـ commits والفروع
- التعامل مع pull requests على GitHub
- حل التعارضات (merge conflicts)
